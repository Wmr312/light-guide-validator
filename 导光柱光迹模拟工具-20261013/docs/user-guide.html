导光柱光迹模拟工具 · 软件使用说明

面向结构工程师的导光柱设计验证工具 — 导入 3D 模型 · LED 灯珠选型 · 光线追踪 · 光斑分析 · 一键报告

适用版本：v3.0 · 文档更新：2026-11-11

一、软件简介

导光柱光迹模拟工具（light-guide-validator）用于在开模 / 打样之前快速验证导光柱方案的出光效果。导入结构工程师建好的三维模型，选择材料与 LED 灯珠型号，程序用光线追踪（Möller–Trumbore 求交 + Beer-Lambert 吸收 + 能量账本）统计出射端与侧壁的能量分布，给出光斑、均匀性与达标结论，并可一键生成验证报告。

典型应用：仪表导光柱、指示灯导光件、按键背光、机箱 / 服务器面板导光等需要在指定区域均匀出光的透明零件。

定位说明：本工具的几何来源统一为导入的三维模型。软件不再提供参数化建模示例，也不提供侧棱镜微齿等附加结构生成 —— 模型长什么样，仿真就按什么样计算，所见即所得。

二、快速上手（六步出结果）

  1. 进入 Home 启动页 — 新建或打开一个项目。每张项目卡片下方带 3D 预览图，可直接看到是哪个零件。
  2. 导入模型 — 进入「模型配置 → 文件导入」，选择 STL / OBJ / STEP 文件；同时设定 LED 与入光面之间的装配间隙。
  3. 选材料与灯珠 — 材料选型下拉选 PMMA / PC 等常用料；LED 灯珠选型库选封装型号（如 0603）、亮度档位，如需查看装配偏心可填 X / Y 偏移。
  4. 设定端面 — 进入「仿真计算」，点「自动检测端面」，或用拾取按钮手动点选入射面 / 出射面（Shift + 点击可累加多个面）。
  5. 开始计算 — 先选「快速预览」看光路走向，确认无误后切「精确评估」出定量结论。
  6. 看结果 / 出报告 — 「结果分析」看指标、曲线与出射端面光斑，「报告生成」勾选记录一键出报告。
第一次使用？参数标签旁的 ? 图标鼠标悬停即可看到含义与建议取值（可在顶栏「选项」中开关）。

六、仿真计算

6.1 仿真模式

模式特点适用场景
快速预览秒级出光路，光斑为低样本平滑估计前期方案迭代、看光往哪走
精确评估定量评估，输出完整工程结论，耗时更长定稿评审、出报告
均匀度与达标判定请以「精确评估」结果为准；快速预览只用于看趋势。

6.2 端面设定

自动检测：点「自动检测端面」，软件按面积与朝向自动识别入射端与出射端。

手动拾取：点「拾取→入射端」或「拾取→出射端」进入拾取模式：

操作效果
单击某个面选中该面（自动扩展整个相连的平面 / 曲面区域），替换当前选择
Shift + 单击在当前选择上累加新的面（用于复杂模型多面入射）
再次单击已选中的面取消该面的选择
拖拽旋转视角不会误触发拾取（位移超过 5px 自动忽略）
Esc 或再次点击拾取按钮退出拾取模式

平面与曲面（如穹顶、圆柱侧壁）在相切交界处会自动分割，尖锐边自动阻断，避免「点一个面带走一整片侧壁」。

6.3 多灯珠

点「+ 增加灯珠」可添加多颗灯珠，每颗灯珠独立选择入射面与出射面，已有参数保留不变。状态栏显示「灯珠×N」。

开启「启用 LED 灯珠」后，灯珠沿所选入射面法向自动定位在面前的间隙处，发射方向垂直入射面。

6.4 公差扫参与运行

勾选「公差扫参」会额外自动运行 LED 偏移 0.1 / 0.2 / 0.3 mm 三组仿真，结果用于结果页的公差-亮度衰减曲线。点「开始计算」后界面显示进度，仿真在后台 Worker 中执行，不卡界面。

十二、常见问题 FAQ

参数化建模（圆柱 / 锥台输入参数生成）去哪了？

已移除。本工具现在的几何统一来自导入的三维模型，目的是让仿真对象与结构实际设计完全一致，避免「参数化近似」与真实模型之间的偏差。请用 CAD 导出 STL / STEP 后导入。

侧棱镜微齿（SPEOS 式）选项在哪？

已移除。侧壁的齿纹 / 微结构请直接建在三维模型里，导入后按真实几何参与光线追踪；表面粗糙程度则用「表面处理与曲面 → 咬花 / 雾面」控制。

导入的模型刷新页面后不见了？

浏览器安全策略限制网页直接读取本地文件缓存，文件模型刷新后需重新导入；项目参数与仿真记录不受影响（存于 localStorage）。建议在一次会话内完成仿真与出图。

X / Y 偏移会不会把导光柱模型也移动？

不会。X / Y 偏移只移动 LED 灯珠本身（沿入射面切线方向），导光柱模型保持原位。这正是模拟「贴片偏位 / 装配公差」的方式。

光线大量在内部反射，出光很少？

按顺序检查：① 材料折射率是否合理（n 越大越「锁光」，PMMA≈1.49）；② 出射端面是否选对；③ 侧面咬花等级是否过低（镜面侧壁会全反射）；④ 查看能量账本，确认能量停在「残留」还是被「吸收」；⑤ 检查 LED 是否与入光面对准（装配间隙与 X / Y 偏移）。

为什么手动拾取入射面后灯珠没有对准？

启用「启用 LED 灯珠」后，灯珠会自动定位在所选入射面法向的间隙处。若未对准，确认已重新导入 / 更新模型，并重新选择端面触发刷新。

想要多个入射面、多颗灯珠怎么操作？

在「仿真计算」点「+ 增加灯珠」，每颗灯珠独立拾取入射面与出射面。同一颗灯珠内可用 Shift+点击 累加多个面。

仿真很慢？

先用「快速预览」迭代方案；需要定量时再切「精确评估」。仿真在后台 Worker 中执行，界面不卡顿。

数据保存在哪里？如何换电脑？

全部数据保存在本机浏览器 localStorage；用 Home 页的「全部导出」备份，「导入文件」还原。请勿使用无痕模式。
