01

行业痛点

研华工程师在导光柱开发中面临四大核心痛点

① 反复开模打样

单次周期 1–2 周，一个项目 3–5 轮才能收敛，模具费累计数万至数十万元

② 出光效果靠经验

棱镜角度、周期全凭老师傅感觉，热点暗斑频发，无法在设计阶段预知

③ 侧壁漏光难定位

全反射临界角外的大角度光线从侧壁泄漏，整机装配后才发现壳体透光

④ 设计变更成本高

客户一改外观形状，整套光学验证推倒重来，项目进度被严重拖累

传统开发流程：结构设计 → 开模打样 → 点亮测量 → 发现问题 → 修模/改结构 — 一轮循环 1–2 周，3–5 轮才能收敛
02

软件概览

解决方案 — 自研轻量蒙特卡洛光追验证平台：纯前端 · 零部署 · 浏览器即用

零安装 · 即开即用

纯 HTML/JS 实现，浏览器打开即用，无需 SPEOS/TracePro 授权费

蒙特卡洛光线追迹

Möller–Trumbore 求交 + Beer-Lambert 吸收 + 空间网格加速 + Web Worker 后台计算

参数化几何 + STL 导入

参数化直圆柱/圆锥台 + 侧壁微齿渐变；矩形导光柱 / LGP 薄板经 STL/OBJ/STEP 导入

多灯珠自动放置

选取多个入射面自动按平面聚类放置多颗 LED，光线按面积加权分配

实时 3D 可视化

光线轨迹、出射端热图、轴向分布、配光曲线、光斑伪彩云图与能量账本；结果自动判定「设计合格 / 需优化 / 不合格」

仿真 vs 实测对比

CSV 批量导入实测数据，仿真与实测指标同表对比，一键生成 HTML 报告

物理模型边界：介质按纯吸收（Beer-Lambert）建模，不含体散射 —— 含扩散粉工艺的出射均匀度按保守下界评估
03

核心能力

从结构设计到出光品质 — 全链路数字化验证

1参数化几何建模直圆柱/圆锥台 + 侧壁微齿（SPEOS 式 85°→10° 线性渐变）；径向分段 24–48；齿距/齿宽/偏移精确可控
2多灯珠自动放置拾取入射面后按平面聚类自动放置 LED 灯珠；选择几个入射面放几颗灯珠；光线按面积加权分配
3实时 3D 光线可视化绿色=到达出射端有效光线；红色=侧壁漏光；出射端 2D 照度热图 + 沿轴分布 + 配光极坐标曲线
4能量守恒账本出射 / 侧面出光 / 吸收 / 残留 — 四象限能量分解，精确定位「光去哪了」
5仿真 vs 实测对比CSV 批量导入实测照度数据；仿真与实测均匀度/CV/照度均值同表对比；偏差一目了然
